# TeX Core 0.1.0

The first published artifact of TeX Core: the npm trusted-publisher
bootstrap release of `@nouprax/es-tex-core`, establishing the package's
publishing identity ahead of the coordinated 1.0.0 release across all
ecosystems.

TeX Core compiles self-contained LaTeX source — a single file or a single
block — into an immutable, platform-neutral render tree with fully
resolved layout. This release ships the walking-skeleton engine surface
(ordinary atoms and explicit spacing) behind the frozen render-tree
schema, version 1: the schema, canonical dump, and structured error
contracts are stable, and every future surface extension is a reviewed
schema change.

- `Document.compile` over three input modes (`document`, `mathInline`,
  `mathDisplay`), returning a frozen value tree of `hbox`/`glyph`/`kern`
  nodes with resolved geometry in points.
- Byte-deterministic canonical dumps, identical across every platform
  binding of the same engine commit.
- Structured fail-fast compile errors carrying the offending source byte
  range and a deterministic message.
